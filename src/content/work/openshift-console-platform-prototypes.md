## Approach

I partner with UX, engineering, and documentation peers to translate fuzzy problem spaces into testable flows. When words and static wireframes stall, I build interactive prototypes in PatternFly so teams can walk the UI together before code lands.

## Process

- Mapped jobs-to-be-done with PM and engineering for networking and GitOps-adjacent workflows.
- Explored list/detail patterns, empty states, and progressive disclosure for dense Kubernetes objects.
- Published hosted prototypes for async critique (networking topology, GitOps rollouts, workload drill-downs).

## Outcome

Shared vocabulary across design and engineering earlier in the cycle. Prototypes became the reference for spacing, component choice, and copy tone in downstream implementation conversations.
