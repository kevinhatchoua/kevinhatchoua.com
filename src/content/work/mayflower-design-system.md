## Context

Dozens of agencies relied on shared code and design patterns. Documentation and visual standards were scattered across tools.

## Approach

Co-led roadmap for Mayflower: style guide, React component library, Pattern Lab, and GitBook documentation. Anchored decisions in research and implementation constraints.

## Process

- Defined Mass.gov brand pillars within the broader Commonwealth identity.
- Authored style guide pages with developers and PMs.
- Consolidated assets and guidance into a single source of truth.

![Mayflower style guide](/images/work/mayflower-design-system.png)

## Outcome

Teams could ship accessible, on-brand experiences faster with shared components and documented patterns.

## Reflection

Government design systems are public infrastructure. Clarity is a civic good.
